# A-Z Offline English–Polish Vocabulary Lookup

A lightweight, fully offline English-to-Polish vocabulary lookup and sentence assembler built with pure HTML, CSS, and JavaScript.

This project allows users to:

- Translate simple English sentences word-by-word into Polish
- Load large JSON dictionary files locally
- Browse and search a built-in A–Z vocabulary list
- Use everything entirely offline in the browser

---

# Features

## Offline Translation
Translate English sentences into Polish directly in the browser without any internet connection.

Unknown words are automatically wrapped in brackets:

```text
Input:
The quick brown fox

Output:
(Ten/ta/to) szybki brązowy [fox]
